## Overview

This is a WordPress plugin demonstrating integration of the WordPress AI Client library with the WordPress Abilities API. It showcases AI-powered post generation with both text content and featured images through a React-based admin interface.

## Development Commands

### PHP Dependencies
```bash
# Install Composer dependencies
composer install

# Check PHP code against WordPress Coding Standards
vendor/bin/phpcs --standard=WordPress wp-ai-sdk-demo.php
```

### JavaScript Build
```bash
# Install npm dependencies
npm install

# Build production assets (outputs to build/ directory)
npm run build

# Development mode with hot reload
npm run start
```

### WordPress Activation
```bash
# Activate plugin via WP-CLI
wp plugin activate wp-ai-client-demo

# Deactivate plugin
wp plugin deactivate wp-ai-client-demo
```

## Architecture Overview

### Entry Point and Initialization
- **Main file**: `wp-ai-sdk-demo.php` (330 lines, all plugin logic)
- Loads Composer autoloader first to enable vendor dependencies
- Hooks into WordPress lifecycle via standard action/filter hooks:
  - `init` - Initializes AI Client
  - `admin_menu` - Registers Tools submenu page
  - `admin_enqueue_scripts` - Loads JavaScript assets on plugin page
  - `wp_abilities_api_categories_init` - Registers ability category
  - `wp_abilities_api_init` - Registers the generate-post ability

### Component Interaction Flow

```
Admin UI (React) → Abilities API → AI Client → PHP AI SDK → AI Provider
     ↓                ↓                ↓              ↓
SettingsPage → executeAbility() → prompt() → PromptBuilder → OpenAI/Anthropic/Ollama
     ↓                                ↓
DataForm/Button              generate_text()/generate_image()
     ↓                                ↓
 User Input                  WordPress Post + Media
```

### Key PHP Functions

All functions use `wp_ai_client_demo_` prefix:

- `wp_ai_client_demo_init()` - Initializes AI Client and registers custom providers (line 29)
- `wp_ai_client_demo_register_ollama_provider()` - Registers Ollama provider with the AI Client registry
- `wp_ai_client_demo_register_local_ai_settings()` - Registers Local AI Models settings page under Settings menu
- `wp_ai_client_demo_get_ollama_models()` - Fetches available Ollama models from localhost:11434 API (cached for 5 minutes)
- `wp_ai_client_demo_local_ai_settings_page()` - Renders the Local AI Models settings page with model selection
- `wp_ai_client_demo_generate_post($args)` - Main ability callback; orchestrates post creation
- `wp_ai_client_generate_content($prompt)` - Generates text, uses selected Ollama model if configured (via `wp_ai_client_demo_ollama_model` option), otherwise falls back to automatic provider selection
- `wp_ai_client_demo_create_image($title)` - Generates image via automatic provider selection (Ollama doesn't support images, so this uses cloud providers)
- `wp_ai_client_demo_create_post($title, $content, $image)` - Inserts WordPress post as draft
- `wp_ai_client_demo_image_to_media($image, $filename, $post_id)` - Converts base64 image to WordPress attachment

### JavaScript Structure

- **Entry**: `src/index.js` - Renders React component into `#wp-ai-client-demo-app` container
- **UI Component**: `src/components/settings-page.jsx` - Main settings page with form and status notices
- **Build Output**: `build/index.js` + `build/index.asset.php` (auto-generated by wp-scripts)

The React component uses WordPress-specific packages:
- `@wordpress/components` - UI components (Heading, Notice, DataForm, Button)
- `@wordpress/element` - React wrapper
- `wp-abilities` script - Provides `getAbility()` and `executeAbility()` functions
- `wp-ai-client` script - Provides client-side `wp.aiClient.prompt().generateText()` API

### Abilities API Integration

The plugin registers one ability: `wp-ai-client-demo/generate-post`

**Input Schema**:
```json
{
  "title": "string (post title)",
  "prompt": "string (content generation prompt)"
}
```

**Output Schema**:
```json
{
  "message": "string (status message)",
  "post_id": "integer (optional, ID of created post)"
}
```

**Permission**: `current_user_can('edit_posts')`

Abilities are invoked via JavaScript using `executeAbility('wp-ai-client-demo/generate-post', input)` which routes through the Abilities API REST controller to the PHP callback.

### AI Client Integration

The plugin depends on `wordpress/wp-ai-client` (v0.2.1+) which wraps `wordpress/php-ai-client`. Key usage patterns:

**Text Generation**:
```php
$result = \WordPress\AI_Client\AI_Client::prompt($prompt)->generate_text();
```

**Image Generation**:
```php
$image = \WordPress\AI_Client\AI_Client::prompt($prompt)->generate_image();
$base64 = $image->getBase64Data();
$mime = $image->getMimeType();
```

**Provider Registration** (for custom providers like Ollama):
```php
$registry = \WordPress\AiClient\AiClient::defaultRegistry();
$registry->registerProvider(\WpAiClientDemo\ProviderImplementations\Ollama\OllamaProvider::class);
```

**Error Handling**: Use try-catch blocks; exceptions are converted to `WP_Error` objects.

**Custom Timeout**: Filtered via `wp_ai_client_default_request_timeout` (set to 60 seconds in this plugin, increase to 120+ for slower local models like Ollama).

**Provider Capability Limitations**: Not all providers support all capabilities:
- OpenAI: Text generation + Image generation
- Anthropic: Text generation only
- Ollama: Text generation only (no image generation)

### Content Generation Workflow

1. User enters title and prompt in React form
2. JavaScript calls `executeAbility()` with input data
3. PHP callback `wp_ai_client_demo_generate_post()` orchestrates:
   - Generate text content with automatic WordPress Block Editor markup appended to prompt
   - Generate featured image based on title
   - Create WordPress post as draft with `post_type: 'post'`
   - Upload image to media library and set as post thumbnail
4. Return success/error message and post ID to frontend

## Code Conventions

### WordPress Standards
- Follow WordPress Coding Standards (WPCS v3.0)
- Use WordPress phpcs.xml configuration from vendor dependencies
- Procedural PHP functions for plugin code (not classes)
- Function names: `wp_ai_client_demo_*` prefix with underscores
- Ability names: `plugin-slug/action` format with dashes
- All text strings wrapped in `__()` or `esc_html__()` for i18n

- Permission checks via `current_user_can()` in ability callbacks
- Input sanitization using `sanitize_text_field()` and `sanitize_file_name()`
- ABSPATH check at top of main file (`if ( ! defined( 'ABSPATH' ) ) exit;`)
- Nonce and permission validation handled automatically by Abilities API REST endpoints
- Admin page assets only enqueued when `$screen->id === 'tools_page_wp-ai-client-demo-tools'`

### File Organization
- Single-file plugin: all PHP logic in `wp-ai-sdk-demo.php`
- Ollama provider implementation in `includes/ProviderImplementations/Ollama/`:
  - `OllamaProvider.php` - Main provider class
  - `OllamaModelMetadataDirectory.php` - Model discovery via /api/tags
  - `OllamaTextGenerationModel.php` - Text generation implementation
  - `NoAuthRequestAuthentication.php` - No-authentication handler for local access
- React components in `src/components/`
- Build output excluded from version control (listed in .gitignore)
- Distribution excludes: source files, node_modules, composer.json, lock files (see .distignore)

## Important Notes

### AI Provider Configuration
AI provider credentials are NOT configured in this plugin. They must be set through the AI Client's settings screen (Settings > AI Client in WordPress admin).

**Supported Providers:**
- **Cloud Providers**: OpenAI, Anthropic (require API keys configured in Settings > AI Client)
- **Local Providers**: Ollama (no API key required, runs on localhost:11434)

### Ollama Provider Integration
This plugin supports the Ollama provider for local AI model usage. Ollama enables running models like Llama 2, Mistral, and others locally without requiring cloud API keys.

**Key Points:**
- Ollama runs as a local server (default: `http://localhost:11434`)
- No authentication required (local access only)
- Supports text generation only (no image generation)
- Models must be pulled before use (e.g., `ollama pull llama3.2`)
- Registration happens during plugin initialization via `wp_ai_client_demo_register_ollama_provider()`
- **Settings Page**: Users can select their preferred Ollama model via **Settings > Local AI Models**
- Model selection is stored in `wp_ai_client_demo_ollama_model` option
- Available models are fetched from Ollama API and cached for 5 minutes

**How It Works:**
1. User navigates to Settings > Local AI Models
2. Plugin fetches available models from `http://localhost:11434/api/tags`
3. User selects their preferred model and saves
4. When generating content, `wp_ai_client_generate_content()` checks if an Ollama model is selected
5. If selected, it uses explicit model instantiation: `OllamaProvider::model($model_id)`
6. If not selected, falls back to automatic provider/model selection

**Documentation**:
- See `OLLAMA-INTEGRATION.md` for complete setup instructions, troubleshooting, and best practices
- See `OLLAMA-MODELS.md` for model recommendations and how to switch between different Ollama models

### Block Editor Markup
Content generation automatically appends "Make sure the response uses WordPress Block Editor markup" to prompts, ensuring generated content is compatible with Gutenberg.

### Image Processing
Generated images are base64-encoded and converted to WordPress attachments using `wp_insert_attachment()`. The `wp_generate_attachment_metadata()` function requires including `wp-admin/includes/image.php`.

### Asset Building
The `build/index.asset.php` file is auto-generated by `@wordpress/scripts` and contains dependency array and version hash. Never edit this file manually.

### Error Handling Pattern
Mix of `WP_Error` objects and try-catch exceptions:
- AI Client methods throw exceptions on failure
- WordPress functions return `WP_Error` on failure
- Plugin callbacks catch exceptions and convert to `WP_Error` for consistent error handling

### Admin Page Locations
The plugin adds two admin pages:
1. **Tools > WP AI SDK Demo** - Main demo interface for testing AI-powered post generation
2. **Settings > Local AI Models** - Configuration page for selecting Ollama models
